## What is this?

This is my Neovim configuration (init.lua, plugin setup, keymaps, the usual wizardry). It tries to be helpful. It will probably disagree with your machine.

## Notes & warnings

* It's my personal setup: custom keybinds, options, and questionable vim lore. Expect things to be opinionated.
* Start with Neovim's built-in tutor: run `:Tutor` and peek at `example_init.lua`  for a minimal, readable starting point.
* If you want a polished beginner-friendly template, try [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim).
